# Process Activity Test Samples

Target: Windows 10 x64 / .NET Framework 4.7.2 / Release x64.

## Build
Build both projects with `Release | x64`.

Copy outputs into the test directory:

```text
E:\AVtest\samples\Process\
├─ ProcessLifecycleTest.exe
└─ ProcessTarget.exe
```

`ImageLoadTest.exe` is separate and is not part of this package.

## Actions

### PROC-CREATE-001
Precondition: no `ProcessTarget.exe` is running.

```bat
cd /d E:\AVtest\samples\Process
ProcessLifecycleTest.exe create > proc_create_stdout.txt 2>&1
echo ExitCode=%ERRORLEVEL%
type proc_create_stdout.txt
```

Expected core output:

```text
[META] TestCaseID=PROC-CREATE-001
[META] Action=create
[TARGET] Operation=ProcessCreate
[TARGET] TargetPID=<pid>
[RESULT] PASS ExitCode=0
```

### PROC-TERMINATE-001
Precondition: start exactly one target first:

```bat
start "EDR Process Target" /D "E:\AVtest\samples\Process" ProcessTarget.exe
```

Then:

```bat
ProcessLifecycleTest.exe terminate > proc_terminate_stdout.txt 2>&1
```

Expected:

```text
[META] TestCaseID=PROC-TERMINATE-001
[TARGET] Operation=ProcessTerminate
[RESULT] PASS ExitCode=0
```

### PROC-ACCESS-001
Start exactly one `ProcessTarget.exe`, then:

```bat
ProcessLifecycleTest.exe access > proc_access_stdout.txt 2>&1
```

Expected:

```text
[META] TestCaseID=PROC-ACCESS-001
[TARGET] Operation=ProcessAccess
[TARGET] DesiredAccess=PROCESS_QUERY_INFORMATION
[RESULT] PASS ExitCode=0
```

### PROC-REMOTE-THREAD-001
Start exactly one `ProcessTarget.exe`, then:

### PROC-TAMPER-001
Start exactly one `ProcessTarget.exe`, then:


## Validation rule
A run is valid only when it contains all of:

```text
[RUN-BEGIN]
[META] TestCaseID=<expected ID>
[META] PID=<actor pid>
[META] RunStartUTC=<UTC>
[SETUP-BEGIN]
[SETUP-END]
[TARGET-BEGIN]
[TARGET-END]
[RESULT] PASS ExitCode=0
[RUN-END]
```

For `terminate/access/remotethread/tamper`, the test program deliberately does **not** create the target in SETUP. The target must already be running so that the action under test is not contaminated by an extra Process Create generated by `ProcessLifecycleTest.exe`.
